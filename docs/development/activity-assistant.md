# 轨外回响辅助 (实验版)

## 使用

1. 启用安魂曲配置任务; 无需打开 `启用手动触发按键` 总开关。
2. 在最外层 `活动配置` 中打开 `轨外回响辅助`。
3. 原有 `方案输入方式` 选择 `后台(发消息)` 可后台运行; 前台硬件模式要求游戏前台。
4. 进入活动后按 `5` 开始, 再按一次停止。可改为 `mouse4` 或 `mouse5`。
5. 同键时活动优先; 运行中不执行本任务其他手动宏。活动开关关闭、任务关闭、程序暂停会停止。
   活动开关独立于手动触发总开关; `活动配置` 仅用于展开/收起, 不是运行开关。

不要同时启用其他自动战斗/输入任务。本控制器不会停止用户开启的其他任务;
发现 executor 正在执行其他任务时自身停止。重新启动需要再次按活动键。
后台仍须游戏截图可用; 窗口最小化或画面停更不能保证可运行。

## 功能及边界

- 红色候选分割、轮廓填充、圆环补全、重叠区域合并及安全余量。
- 八方向搜索连续安全出口, 普通 WASD 每次最多约 80ms, finally 释放已按键。
- OCR 必须确认活动 HUD 才允许移动; 截图处理超过 500ms 不发送基于旧帧的移动。
- 连续 4 秒未离开危险范围停止, 不无限撞墙。不含地图导航、可靠障碍识别或拾取。
- 当前按固定跟随镜头脚底坐标计算, 默认宽度 0.5、高度 0.565; 可在本组校准。
  不包含通用角色检测, 镜头旋转、角色偏离该位置时不可直接使用。
- 红色攻击特效可能误报, 暗色/严重遮挡的预警可能漏报; 不能保证无伤。
- 选卡 OCR 连续两次一致才点击, 同一弹窗只点击一次; 需要确认返回活动 HUD 才重置。
- `选卡优先级` 为逗号分隔的卡名/明确短语, 从左到右优先。空值、未匹配或不稳定时等待手选。
  不随机选卡, 不刷新、不剔除、不退出重开、不主动结算。
