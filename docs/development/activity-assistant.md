# 活动辅助 (实验版)

启用安魂曲配置任务和活动独立开关, 按自定义热键启停, 支持后台。

## 通用文字点击

保留配置键 `选卡优先级`, 现在适用于任意游戏页面。
例如填写 `无尽挑战/开始挑战/传说能力/定时回复生命`, 按从左到右顺序优先。
支持斜杠、逗号、换行; 点击OCR实际文字中心, 不限卡牌/固定图片/固定位置。
同一文字持续存在时最多每2秒点击一次。避免常驻文字或过宽关键词造成反复点击。
普通页面未匹配不随机点击; 只有检测到选取卡牌标题且连续10秒未匹配,
才在三个卡槽中随机点击一次。离开选卡、匹配成功或截图失败重置等待。
文字点击及随机卡牌点击均传入框架 `move_back=True`, 恢复点击前鼠标位置。
定时回血词可用整帧放大OCR重试。55项针对性测试与语法/diff检查通过,
未重跑全量或实战验证鼠标恢复。

## 移动与限制

活动场景先检查危险, 脚下危险时跳过文字点击, 优先撤离。
文字扫描和点击冷却仅表示本次没有点击, 不阻止红区判断。
菜单及其他页面仍可点击配置文字, 活动局内一律禁止配置文字点击。
右上角“伤害跳字” (开/关均可) 为共用局内标识, 扩大OCR区域覆盖该按钮。
旧活动标题和无尽挑战加计时器作为备用判断。用户截图已识别“伤害跳字: 开”。
本次53项针对性测试通过; 未全量重跑或真实游戏验证。
点击日志记录命中的用户配置词, 不记录整屏OCR文本。
本次49项针对性测试、语法和diff检查通过; 未全量重跑或真实游戏验证。

红区移动仍要求活动HUD确认; 文字点击不受此限制。截图暂时失败时等待恢复且不输入。
移动/识别由executor串行执行, 热键独立监听。单次移动0.05~1秒, 默认0.2秒。
不因危险持续时间自动停机。大圆预警才允许右键, 间隔至少1秒。
方向先按60ms, 右键先松再正常保持方向30ms; 停止/异常路径释放输入。
方向累计以启动点为原点, 闪避额外折算步行秒数 (默认1秒, 待校准)。
请在场地中央启动; 不等于真实地图定位, 不保证始终居中或无伤。
脚底比例是屏幕人物脚底位置, 不是地图中心。后台仍需可用截图。
