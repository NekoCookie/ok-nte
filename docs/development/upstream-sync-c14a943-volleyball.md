## Post-migration incident evidence

The migrated COCO annotations used image id `43`, but that id referenced the local compressed
`assets/images/1.png`. The annotated restart, next-level, star, and star-region crops were all
pure white pixels. Consequently restart matched during active play, and the star-region search
returned four artificial matches for a three-star screenshot. These labels and annotations are
removed by I-04; no user screenshot or local runtime artifact is committed.
