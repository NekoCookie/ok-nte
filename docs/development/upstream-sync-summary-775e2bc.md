# 上游 UI 适配同步成果总结

## 目的

将上游 `main` 的 `775e2bc` 同步到本地 `requiem-main-dps`，吸收游戏新版 UI 相关适配，并迁移本地 LW 定制逻辑到更新后的 RU 基线上。

## 同步范围

- 场景坐标改为 `PositionMap` / `PanelPosition` 结构化管理，更新屏幕位置映射。
- 更新礼物菜单布局、礼物入口识别和相关 OCR 流程。
- 同步深渊任务、任务/UI 模块重组、运行时服务及资源调整。
- 同步 Planner、角色注册/自定义角色数据和动作协作接口变更。
- 加入黑羽角色逻辑，并升级到 `ok-script 2.0.4` 及上游锁定依赖。
- 保留 `src/lw/` 本地扩展；将与新版接口冲突的 LW 接线迁移到新契约，没有恢复旧 RU 实现或增加 A/B 双路径。
- Requiem 固定切人流程显式设为切入即完成；Planner 的 `for_switch()` 默认仍遵循上游“切入后等待目标完成一轮”的语义。

尚未在更新后的真实游戏窗口做人工冒烟验证，因此同步账本保持 `open`。建议检查：

1. 1080p / 1440p 下主界面、地图、队伍、礼物和任务面板的定位与点击。
2. 新布局下礼物入口及收礼角色 OCR 识别。
3. 深渊任务的一条完整路线，包括暂停、恢复或传送后的状态恢复。
